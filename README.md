# Heat Transfer Summary Portal

A lightweight study web app for reviewing selected **heat transfer** topics and key formulas.

The current content covers:

- Chapter 9 — Free Convection
- Chapter 10 — Boiling and Condensation
- Chapter 11 — Heat Exchangers

## Project highlights

- Subject-oriented navigation for engineering study material
- Chapter summaries and formula-focused reference pages
- Responsive card-based interface
- Simple example of turning mechanical-engineering study material into a web learning tool

## Stack

- Next.js
- React + TypeScript
- Tailwind CSS

## Status

This is a small supporting academic project rather than a primary portfolio showcase.

## Local development

```bash
npm install
npm run dev
```
