# Heat Transfer Summary Portal

Small study web app for selected heat-transfer topics and formulas.

## Coverage

- Chapter 9: Free Convection
- Chapter 10: Boiling and Condensation
- Chapter 11: Heat Exchangers

## Stack

`Next.js` `React` `TypeScript` `Tailwind CSS`

## Development

```bash
npm install
npm run dev
```

Supporting academic project, not a primary portfolio showcase.
